# 第十四章 老周

海城的码头跟我小时候差不多。还是那些船，还是那些人，{空气|kōngqì}里还是鱼和海水的味道。只是有几条船新了，有几个人老了。

我一下火车，就去了码头。

一个老人坐在一条小船的旁边，在补渔网。他的头发全白了，脸很黑，手很大。他补渔网的样子，跟十年前一模一样。

他抬起头，看见我，好像一点儿也不奇怪。

"你来了，"他说，"坐吧。"

"老周，"我说，"奶奶走的那天，站在最后面的人，是你。"

"是我。"他放下渔网，"走吧，去我家喝杯茶。"

老周的家就在码头旁边，很小，可是很干净。墙上有很多照片，都很旧了。我在一张照片上看见了奶奶。她很年轻，{梳着|shūzhe}两条长长的{辫子|biànzi}，站在一条船的前面笑。她的旁边，是一个又高又瘦的年轻人。

"那是我，"老周说，"那年我们十六岁。"

他给我倒了一杯茶，自己也倒了一杯。

"你跟我奶奶，认识多久了？"我问。

"五十年了，"老周说，"不对，六十多年了。我们是小学同学。她走以前，跟我说了很多你的事。她说，你从十八岁开始，就做那个梦。她说，要是有一天你回来找那个门，让我帮你。她说你会来的。她说你跟她一样，说了不听，什么事都要自己去看看。"

我笑了，眼泪却流了下来。

"你怎么知道那个帖子是我写的？"

老周笑了一下。"我孙子教我上网，"他说，"你奶奶走了以后，我每天都在网上找。找了半年。我找的是'石头门''链子''二十八岁'。找到了很多没用的东西。可是你的帖子，我一看就知道。"

我从包里拿出那个小铃，放在桌子上。

老周看着铃，看了很久，没有碰它。

"{葬礼|zànglǐ}那天，它响了，"他说，"我就知道，时间到了。"

"老周，你也知道那个故事吧？会用火的人，那个女孩儿，那个门。"

"你奶奶给你讲的，是城里人的故事。"老周说，"我们打鱼的人，还有另一个故事。我爷爷讲给我爸爸，我爸爸讲给我。我从来没有讲给别人听过。"

他喝了一口茶，慢慢地说：

"三百年前，城里的人把那个男人带到海上。可是，链子是锁不住他的。他能把火拿在手里，什么样的链子，他都能{弄断|nòngduàn}。

"所以，那个女孩儿做了一件事。她用刀把自己的手弄{破|pò}了，把自己的血放在了锁上。她用她自己的{命|mìng}，把他锁住了。

"从那以后，只有一件事能打开那把锁。"

"什么事？"我的声音很小。

"他再看见她。"老周说，"他再看见她的那一天，锁就开了。链子就断了。可是同一天，他必须杀了她。这是锁的{一部分|yībùfèn}，也是诅咒的一部分。"

我坐在那里，一动也不动。

"你明白了吗，孩子？"老周说，"{钥匙|yàoshi}和诅咒，是同一个东西。"

外面，有船回来了。我听见了人们的笑声，听见了海水的声音。可是这些声音，都好像离我很远很远。

我想起阿夜从来不看我。我想起他说：要是你爱我，就不要来找我。我又想起门后面那个低低的声音：快来，时间不多了，带上那个铃。

我把这十年的事情，都告诉了老周。他不看我的脸，只看水里的我。那个诅咒。那两个声音，一个让我别来，一个让我快来。还有那天晚上，他放在我脖子上的手，和他在我耳边说的"快走"。

老周一直听着，一句话也没说。他的茶已经凉了，他也没有喝。

我说完了，房间里很安静。

"老周，"我问，"他是好人，还是坏人？"

老周想了很久。

"我不知道，"他说，"我只知道，要是他是坏人，他会等你。他会想办法让你去找他。因为只有你去了，他才能出来。

"要是他是好人，他会躲你。他会让你别去，会骂你，会推开你。因为只要你去了，你就会死。"

他看着我。

"可是孩子，你想一想：一个坏人，要是很聪明，他会怎么做？他也会让你别去。他知道，他越不让你去，你越想去。"

我的手冷了。

"所以，从这里，"老周说，"你是看不出来的。好人和坏人，从这里看，是一样的。"

"那我怎么才能知道？"

老周没有马上回答。他看着窗外的海，看了很久。

"只有一个办法，"他最后说，"见到他。"

那天晚上，我睡在奶奶的老房子里。我把小铃放在床边。

我等阿夜来。我有很多很多问题要问他。

可是，他没有来。

只有那个低低的声音，在很远很远的地方，叫我的名字。

"林雨。"

一次，又一次。像海水一样。
