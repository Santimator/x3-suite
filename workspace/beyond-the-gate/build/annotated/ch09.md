# 第九章 他的秘密

奶奶的故事，我一直放在心里，两年没有问阿夜。

我{不敢|bùgǎn}问。我怕他说"是"，也怕他说"不是"。

要是他说"是"，那他就是三百年前那个从海里走出来的人。那个会用火的人。那个可能烧了海城的人。

要是他说"不是"，那他是谁？我又为什么会梦见他？

所以，我什么也没问。我还是每个星期去那片灰色的海边，还是给他讲白天的事情。他还是看着水里的我，静静地听。好像什么都没有变。

可是我知道，有什么东西变了。每次我看着他手上的链子，我就会想起奶奶的话：用链子把他锁在了门的那边。

我二十六岁那年的秋天，有一天晚上，我在梦里坐下来，发现自己手里拿着那个小铃。

我不知道它是怎么来的。睡觉以前，它在我的床边。可是在梦里，它在我的手里。

阿夜看着水里的铃，很久没有说话。

"你从哪儿拿到的？"他终于问。他的声音跟平时不一样，{很紧|hěnjǐn}。

"我奶奶给我的。"我说，"阿夜，两年前，我奶奶给我讲了一个故事。"

我把奶奶的故事，一句一句地告诉了他。从海里走出来的男人，手里的火，那个给他送饭的女孩儿，那一夜的大火，第二天的链子。

我一边说，一边看着他。他一动也不动，好像一块石头。

我说完了，停了一下。

"那个人，"我问，"是你吗？"

阿夜没有动。他身上的链子也没有动。整个世界都很安静，安静得我能听见自己的心跳。

过了很长时间，他才开口。可是他没有回答我的问题。

"林雨，"他说，"我要告诉你一件事。听完以后，你就不要再来了。"

"你先说。"

"我身上有一个诅咒，"他说，"我看见你的那一天，我就必须杀了你。"

我一下子不知道该说什么。

"不是我想，"他接着说，他的声音很低，"是我的手。到了那一天，我的手不会听我的话。我会拿起刀，我会……"

他没有说下去。

我看着他。我想起了很多事情。

"所以你从来不看我。"我慢慢地说，"八年了，你一直只看水里的我。"

"是。"

"所以你不让我过去。"

"是。"

"谁给你的诅咒？"

他又不回答了。

"阿夜，"我站了起来，"你告诉我。这是不是就是你不让我过去的{原因|yuányīn}？"

"这是{唯一|wéiyī}的原因。"他说。

"那你是不是那个人？三百年前的那个人？"

他的头低了下去。他还是没有回答。

我等了很久很久。最后，他说了一句话。这句话，我一辈子也不会忘。

"林雨，要是你爱我，就不要来找我。"

那天早上，我醒来的时候，脸上都是{眼泪|yǎnlèi}，{枕头|zhěntou}也湿了一大片。

第二天晚上，我还是去了。

虽然他让我不要来，但是我不知道怎么才能不来。我一睡着，就到了那片海边。这不是我可以选的。

阿夜还坐在那里。他看见水里的我，叹了一口气。

"我说了，不要再来了。"

"我听见了，"我说，"可是我不会不来。阿夜，你听着：你越让我走，我越不会走。"

他没有说话。我们就那样坐着，一个在水的这边，一个在水的那边，跟八年前一样。只是这一次，我们都知道了，我们中间不只有水，还有一个诅咒。

天快亮的时候，他小声说了一句："你跟她一样。"

"跟谁一样？"

可是他已经不见了。

那个星期，我好像丢了{魂|hún}一样。上班的时候，我看着电脑，一个字也写不出来。开会的时候，经理叫了我三次，我才听见。吃饭的时候，我拿着筷子，忘了吃。

小美约我吃饭。她看了我一眼，就说："你怎么了？脸色这么不好。"

"没什么，"我说，"睡得不好。"

"又是那个梦？"

我没有说话。小美叹了一口气，给我的碗里放了很多菜。"多吃一点儿，"她说，"你瘦了。"

那天晚上，我一个人坐在房间里，看着手上的红线，想了很久。

阿夜说，他的诅咒让他必须杀我。所以他不看我，不让我过去，让我不要去找他。

他是在{保护|bǎohù}我。

可是，他为什么不回答我的问题？他为什么不说他是不是那个人？要是他是好人，他为什么不说"我不是"？

我想相信他。我很想很想相信他。

可是那天晚上，我第一次想：他是在保护我，还是他想让我相信，他在保护我？
