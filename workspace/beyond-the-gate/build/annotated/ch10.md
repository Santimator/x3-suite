# 第十章 另一个声音

从那以后，阿夜变了。

他开始{躲|duǒ}我。

有时候，我在梦里走到海边，水的那边只有链子，没有人。链子放在石头上，{空空|kōngkōng}的，一动也不动，好像从来没有人在里面一样。

我叫他。"阿夜！阿夜！"

我叫了很久，只听见他的声音从很远很远的地方来："回去吧。别找我。"

"你在哪儿？你出来！"

可是他不再说话了。

有时候，我整个晚上都在灰色的海边走来走去，从左边走到右边，又从右边走到左边，一直到天亮，连他的样子也没有看见。

我又生气又难过。我想：他怎么能这样？八年了，他怎么能就这样不见了？

他越躲，我越想找到他。

可是，最奇怪的事情，是在一个冬天的晚上发生的。

那天晚上，阿夜又没有来。我一个人坐在水边，看着空空的链子，心里很冷。

突然，我听见了一个声音。

那个声音从门的后面来，从很黑很黑的地方来。它虽然有一点儿像阿夜的声音，但是又不太像：它更低，更慢，每一个字都好像很重。

"快来，"那个声音说，"时间不多了。"

我一下子站了起来。

"阿夜？是你吗？"

"来找我，林雨。"那个声音说，"带上那个铃。"

然后，声音就没有了。

我站在那里，很久都不能动。我的心跳得很快，手上的红线也在疼。

从那以后，这个声音又来了很多次。每次都是阿夜不在的时候。每次说的话都差不多：快来。时间不多了。来找我。带上铃。

开始的时候，我很怕它。后来，我想：我要知道它是谁。

有一天晚上，那个声音又来了。

"快来，林雨。时间不多了。"

"等一下，"我说，我的声音有一点儿发抖，"你要是阿夜，就回答我一个问题。"

那个声音没有说话。可是我觉得，它在听。

"我认识你以后，"我慢慢地说，"你问我的第一个问题，是什么？"

这个问题，只有阿夜知道。我没有告诉过{任何人|rènhérén}，连小美也没有，连奶奶也没有。

黑暗里很安静。我等了很久，以为它不会回答了。

然后，那个低低的声音说："下雨。"

我的手一下子冷了。

"下雨，是什么样子的。"那个声音说，"这是我问你的第一个问题。"

我站在水边，一句话也说不出来。

"你是阿夜，"我小声说，"对吗？"

"来找我，"那个声音说，"你来了，就都知道了。"

那一刻，我真的很想往门那边走。我想走过那片水，走过那个石头门，走到那个很黑很黑的地方去，看看到底是谁在叫我。我的脚已经到了水里。

可是我想起了阿夜的话：你再走一步，我就再也不来了。

我站在水里，一步也没有走。一直到天亮。

过了一个星期，阿夜终于又来了。

他坐在水的那边，跟以前一样，看着水里的我。他看起来很累，比以前瘦了。

我很想跑过去问他：你去哪儿了？为什么不来？可是我没有。我先问了另一件事。

"阿夜，门后面有一个声音。它让我快来。它让我带上铃。"

阿夜一下子不动了。

"它说，时间不多了。"我说，"我问它，你问我的第一个问题是什么。它说：下雨。"

阿夜很久很久没有说话。他看着水，可是我觉得，他什么也没有看见。

"门后面什么也没有，"最后他说，"别听它。"

"可是它知道下雨的事。只有你知道。"

他没有回答。

"阿夜，"我说，"那个声音，是不是你？"

他还是没有回答。他只是又说了一遍："别听它，林雨。不管它说什么，都别听。"

那天晚上，我第一次觉得，我不认识他了。

一个阿夜说：别来，你会死。

另一个阿夜说：快来，时间不多了。

哪一个是真的他？是那个不看我、不让我过去的人？还是那个在黑暗里叫我的人？说不定，两个都是他。说不定，两个都不是。

我想相信他。可是我的问题不是要不要相信他，而是应该相信哪一个他。

第二天，我在城里买了一个新的本子。从那天起，我每天早上一醒来，就把梦写下来：几月几号，他来没来，他说了什么，那个声音说了什么，我手上的红线是什么颜色。

我想，要是我写得够多，说不定有一天，我就能看明白了。

几个月以后，本子写满了一半。我坐在床上，从第一页看到最后一页，发现了一件事：阿夜不来的晚上，那个声音就来；阿夜来的晚上，那个声音就不来。他们两个，从来没有在同一个晚上出现过。

我把本子关上，很久没有动。
