# 第二十一章 海里的路

快到十二点的时候，船停了。

"我只能到这里，"老周说，"前面的水太浅，船过不去。"

我们等着。四周很安静，只有风的声音，还有船下面的水，轻轻地打着船。天上什么也没有，没有月亮，没有星星。我回头看，海边小美的灯还在，很小很小，可是一直在。

我把手放在口袋里，{摸|mō}着手机。我的另一只手里，拿着奶奶给我的小铃。

"老周，"我小声说，"要是我没有回来——"

"别说这个，"老周说，"你会回来的。"

然后，我看见了。

海水在往后走。

开始很慢，慢得我以为是自己看错了。然后越来越快。好像有人在海的另一边，把水一点一点地拉了回去。船下面的水越来越少，船慢慢地停在了沙子上。

在黑黑的水里，慢慢地出来了一些石头。一块，两块，十块……它们一块{挨着|āizhe}一块，最后，变成了一条石头的路。那条路从我们的船边开始，一直到很远很远的地方，到那两块黑石头的中间。

我和老周看着那条路，谁也没有说话。

老周活了七十多年，打了一辈子的鱼。可是我看见，他的手在发抖。

"去吧，"他最后说，"一个小时。记住，一个小时。"

"我记住了。"

我下了船，走上了那条路。

石头又湿又滑，上面有很多海草。我走得很慢，很小心，每一步都先用脚试一试，然后才走。两边都是黑黑的海水，我能听见水的声音，就在我的旁边，可是我看不见水。

我只能往前走。

走到一半的时候，我停了下来，回头看。

后面很远很远的地方，有两个很小的光。一个是老周船上的灯，一个是小美手里的灯。它们那么小，好像我用一只手就能把它们都放进口袋里。

那是我的世界。我的朋友，我的工作，我的城市，我每天早上起来要过的生活。都在那两个小小的光里。

前面，什么也没有。只有黑。只有他。

我在路中间站了很久。我知道，要是我现在回去，没有人会说我不好。小美会抱着我哭，老周会给我做一碗面，我会回到城里，回到我的生活里。{也许|yěxǔ}有一天，我会忘了他。

我想了很久。

然后，我{转过身|zhuǎnguòshēn}，又往前走了。

我走了很久。我不知道走了多久。好像走了十分钟，又好像走了十年。

我一边走，一边想阿夜。

我想起十八岁的第一个梦。他坐在石头上，不回头，说："回去。别过来。"

我想起他问我："下雨，是什么样子的？"我想起他听我讲面条儿的时候，那么认真的样子，好像我说的是世界上最重要的事。

我想起他第一次跟我说"谢谢"。

我想起他站在水里，链子响得像打雷一样，说："你再走一步，我就再也不来了。"

我也想起火里的他。他的脸上有血，手里拿着刀。我想起他放在我脖子上的手，那么冷，那么紧。

我想起那个低低的声音："快来。时间不多了。"

哪一个是他？哪一个是真的阿夜？

我马上就要知道了。

然后，我到了。

两块黑石头，比我在梦里看见的还要大。它们很高很高，像两个很高很高的人，站在黑夜里，一左一右，看着我。

它们中间，就是那个门。

我走过去，用手碰了碰它。

石头很冷，很湿，很粗。上面有很多画，我看不见，可是我的手能摸到。是真的。

十年了。我在梦里看见它一千次。今天，我第一次用手碰到它。

我站在门前，手里的小铃自己响了一下。

叮——

我{深深地|shēnshēndì}{吸|xī}了一口气，走了进去。

门的那边，不是灰色的海。

门的那边，是一个山洞。

山洞里，黑得什么也看不见。不是夜里的那种黑，是一点儿光也没有的黑。我把手放在眼睛前面，也看不见自己的手。我好像一下子没有了眼睛。

我站在那里，不敢动。我能听见自己的心跳，很快，很大声，好像整个山洞都能听见。

然后，我听见了。

在山洞的{深处|shēnchù}，有链子的声音。很长的链子，在石头上慢慢地拖着。一下，又一下。越来越近。

一个声音在黑暗里说：

"你来了。"

是那个低低的声音。门后面那个，叫我快来、叫我带上铃的声音。

可是，它接着说的话，是阿夜的话。

"你不应该来的，林雨。"

我站在黑暗里，一动也不动。

两个声音，是同一个人的。
