# 第十二章 时间不多了

奶奶走了以后，梦变了。

以前的梦，虽然奇怪，但是很安静。灰色的海，灰色的天，阿夜坐在水的那边，我坐在水的这边。我们说话，或者不说话。有时候他不来，有时候那个低低的声音来。可是不管怎么样，那片海总是安静的。

现在的梦，越来越可怕。

我梦见海城着火了。

不是现在的海城，是很老很老的海城。街上的房子都是{木头|mùtou}的，码头上的船也是木头的，很小很旧。火很大，天都是红的。到处都是人在叫，在跑，在哭。一个女人{抱|bào}着孩子，从我的身边跑过去。一条狗站在路中间，一直叫。

我也想跑，可是我的脚不动。我只能站在那里看。

我梦见阿夜站在火里。

他的脸上有血，他的手上也有血。火在他的身边，越来越大，可是他一动也不动。我看不清楚，那是别人的血，还是他自己的血。我也看不清楚，他是在看着火，还是在看着我。

我梦见门那边的链子，一条一条地断了。

开始的时候，他的手上和脚上都有链子。每一次做梦，就少一条。先是右脚，然后是左脚，然后是右手。最后，只剩下一条，在阿夜的左手上，红得像火一样。

每次醒来，我手上的红线都疼得{厉害|lìhài}。

有一天夜里，我梦见他终于过来了。

他从水里走过来。水到了他的腿，到了他的{腰|yāo}，他还是一直走。他走过了那片水，走到我的面前。

十年了，这是他第一次离我这么近。

可是他还是{低着头|dīzhetóu}，不看我的脸。

然后，他的两只手放在了我的脖子上。

他的手很冷，冷得像海水一样。

我想叫，叫不出来。我想跑，脚却不动。我只能看着他的头发，看着他手上那条红红的链子。

"走！"他在我的耳边说，声音很急，"快走！"

他的手越来越紧。可是他的嘴一直在说："走！林雨，快走！"

然后我就醒了。

天还没亮。我跑到洗手间，打开灯，看着{镜子|jìngzi}里的自己。

我的脖子上，有两条红红的{手指|shǒuzhǐ}{印|yìn}。

我在镜子前面站了很久很久。我用手碰了碰那些红印，很疼。

我不明白：他是想杀我吗？他的手在我的脖子上，他的手越来越紧。可是他的嘴在说"走，快走"。

他是在杀我，还是在把我{推开|tuīkāi}？推开什么？推开他自己的手吗？还是推开别的什么东西？那个低低的声音？那个门？

我不知道。我什么都不知道了。

过了三天，阿夜才又来了。他还是坐在水的那边，好像什么也没有发生过。

我坐下来，看着水里的他，很久才开口。

"三天前的晚上，你过来了。你走过了水，到了我这边。"

阿夜没有说话。

"你的手，"我说，"在我的脖子上。阿夜，那是你吗？"

他看着水，过了很久很久，才慢慢地说："我不记得。"

"你不记得？"

"有的晚上，我不记得我去了哪里，做了什么。"他的声音很小，"醒过来的时候，我的手很冷。"

我们两个都不说话了。我听着自己的心跳，他看着自己的手。

我不知道什么更可怕：是他记得，还是他不记得。

那天，我穿了一件高{领子|lǐngzi}的衣服去上班。小美跟我吃午饭的时候，看了我好几次，可是什么也没有问。

我只知道一件事：梦里的阿夜，越来越累，越来越瘦。他的脸白得像纸一样，他的声音也越来越小。有时候，他坐在那里，很久很久都不说一句话。有时候，我叫他三次，他才抬起头。

有时候我觉得，他快要死了。

时间不多了。

那以后的半年，我回到了以前的生活。每天上班，下班，跟小美吃饭，给自己做饭。我没有再去看医生，也没有再跟别人说梦的事。看起来，一切都跟以前一样。

可是我心里，好像一直有一个钟在走。{滴答|dīdā}，滴答，滴答。每一天，都比前一天快一点儿。

然后，就到了我生日前的那个星期。就到了那个凌晨三点。

我醒过来，嘴上是海水的味道，手上的红线又红又热。我打开电脑，写了那个帖子。

我写：他快死了。

我写：他必须杀了我。

我写：请帮帮我。

最后，我写：另，我可以告诉你们更多的细节。

现在，你们都知道了。

这就是那些细节。
