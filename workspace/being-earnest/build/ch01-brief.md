# Scribe brief — chapter 1: 城里的下午

You are the **scribe**. Write this one chapter of a Chinese graded reader. Stay strictly within the permitted vocabulary below. Validation runs right after you, so words outside the list cost a rework — choose the simpler word.

## What happens in this chapter
In his city flat, 阿龙 waits for guests and eats nearly all the cake meant for them, teasing his servant about it. 杰克 arrives from the country and announces he means to ask 高文 to marry him. 阿龙 says he cannot until he explains something first — and goes to fetch a watch 杰克 left behind on an earlier visit. Play the eating comedy and the friendship: 阿龙 light and teasing, 杰克 serious. End on 阿龙 holding up the watch.

## Hard constraints
- Target level: **HSK3**. When in doubt, pick the simpler word.
- Out-of-list budget: **between 1% and 5%** of tokens. The lower bound is deliberate — a chapter with *zero* new words is too easy to learn from. Reach a little beyond the list on purpose (a few words the story needs); each gets glossed once. Compositional combinations of known characters are allowed sparingly (≤ 15%).
- Length: at least **800 characters** of prose — this is checked and will fail the chapter. Write a full, meaty episode, not a summary. Reach the length through more scenes, dialogue, and concrete detail, never through fancier words.
- Expressions: use **at least 5 different constructions** from the list below. This is checked. They are what make the prose sound like Chinese instead of translated English — build sentences around them rather than sprinkling them on.
- Use only the words listed below (plus the story names). Do not invent plot beyond the summary.

## Expressions to build sentences with
Patterns — wrap your own words inside them:
- **太…了** tài … le — too…; really… (emphatic)
- **又…又…** yòu … yòu … — both … and … (two qualities at once)
- **一边…一边…** yìbiān … yìbiān … — doing one thing while doing another
- **因为…所以…** yīnwèi … suǒyǐ … — because …, therefore …
- **虽然…但是…** suīrán … dànshì … — although …, (but) …
- **一…就…** yī … jiù … — as soon as …, (then) …
- **越来越…** yuè lái yuè … — more and more …
- **先…然后…** xiān … ránhòu … — first …, then …
- **一点儿也不…** yìdiǎnr yě bù … — not … in the least
- **不但…而且…** bùdàn … érqiě … — not only …, but also …
- **越…越…** yuè … yuè … — the more …, the more …
- **除了…以外** chúle … yǐwài — apart from …; except for …
- **要是…就…** yàoshi … jiù … — if …, then …
- **只要…就…** zhǐyào … jiù … — as long as …, then …
- **只有…才…** zhǐyǒu … cái … — only if …, (only then) …
- **对…来说** duì … lái shuō — as far as … is concerned; for …
- **好像…一样** hǎoxiàng … yīyàng — just as if …; like …
- **不是…而是…** bù shì … ér shì … — not …, but rather …
- **连…都…** lián … dōu … — even … (does/doesn't)
- **一…也没…** yī … yě méi … — not a single …
